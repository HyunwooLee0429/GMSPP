# GMSPP — Exact and Matheuristic Methods for the Generalized Multiple Strip Packing Problem

Code, instances, and per-instance results accompanying:

> H. Lee and T. Cheong, *Exact and Matheuristic Methods for the
> Generalized Multiple Strip Packing Problem*, submitted to
> Computers & Industrial Engineering, 2026.

The GMSPP packs rectangular items without overlap into open-ended
strips of different widths, where an item's dimensions may depend on
the strip it is assigned to (Vasilyev et al., C&IE 2023). This
repository contains the first exact framework for the problem (a
combinatorial Benders decomposition with H_i-aware conditional
cuts), the LP-PC dual bound and bound portfolio, a certified
ALNS-based matheuristic, and everything needed to reproduce the
paper's computational study.

## Layout

| Path | Contents |
|---|---|
| `gmspp/` | library: instances, formulations (big-M, normal-position master), BendM (Benders + y-check + lifting), ALNS matheuristic, CP-SAT baseline, bounds |
| `run_v2.py` | main experiment driver (blocks `C` = Tier 1 bounds, `B` = Tier 2 certified sweep, `A` = Tier 3 equal-budget campaign); resumes from `results/*.csv` |
| `run_nzw.py` | zero-waste endgame ablation (Appendix A); optional budget arg |
| `fuzz_alns.py` | invariant fuzz harness for the matheuristic (run before campaigns) |
| `gen_tables.py` | regenerates every paper table from the CSVs |
| `results/` | per-instance result files underlying every table of the paper |
| `benchmarks/CLASS`, `benchmarks/ZDF`, `benchmarks/N` | instance families used in the paper (fixed-dimension conversions are deterministic; strip-dependent instances are generated by `gmspp/vasilyev.py` with fixed seeds) |

## Requirements

Python 3.11, [Gurobi](https://www.gurobi.com) 13.0 (license
required), OR-Tools (CP-SAT), NumPy, Numba, pandas.

```
pip install ortools numpy numba pandas
```

## Reproducing the study

```
python fuzz_alns.py 200        # sanity: solver invariants (minutes)
python run_v2.py C             # Tier 1: relaxation strength
python run_v2.py B             # Tier 2: certified-gap sweep (~1 day)
python run_v2.py A             # Tier 3: equal-budget campaign (~1 week)
python run_nzw.py              # Appendix A ablation (~half day)
python gen_tables.py           # rebuild all paper tables
```

All experiments resume from their CSVs, so interrupted runs can
simply be restarted. Reported hardware: i9-13900F (24 cores), 64 GB
RAM, Windows; Gurobi capped at 16 threads per solve.

## Acknowledgment and provenance

The y-check component (`gmspp/ycheck.py`) implements the y-check
algorithm of Côté, Dell'Amico, and Iori (Operations Research,
2014); its design was informed by the original C implementation
generously shared by Jean-François Côté. See the paper
(Section 4.5) for details.
